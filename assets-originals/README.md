# 原始素材归档目录

这里用于保存博客文章的原始素材，例如未压缩 PNG 截图、设计源文件、录屏、导出前文件等。

这个目录不在 `src/content/posts/` 或 `public/` 下，文章资源扫描不会收集这里的文件，因此不会进入 `docs/assets/` 发布产物。

使用规则：

- 不要在 Markdown 文章中直接引用这里的文件。
- 文章展示用图片应放在对应文章目录下，并优先使用压缩后的 WebP。
- 如果需要保持清晰度，使用 lossless WebP 转换后再放入文章目录。
- 原始文件按文章或主题建立子目录保存。
- 不要把原始大图放到 `src/content/posts/` 或 `public/`，否则会参与打包或发布。
